# querychat on Groq

A one-file [querychat](https://posit-dev.github.io/querychat/) Shiny app running on
[Groq](https://console.groq.com/)-served open models, plus an [inspect_ai](https://inspect.aisi.org.uk/)
eval suite that measures how four of those models behave under the prompt customizations taught in
DSCI 532 lecture 5.

- **Repo:** <https://github.com/ilyamusabirov/532-groqdemo>
- **[Porting guide](porting.html)** — move any 532 LLM demo to Groq: which models, which line to change, what breaks
- **[Eval report](eval-report.html)** — the model × prompt-config results, regenerated by `evals/run_matrix.sh`

## Run the demo

Requires [uv](https://docs.astral.sh/uv/) and a Groq API key (free at <https://console.groq.com/keys>).

```bash
git clone https://github.com/ilyamusabirov/532-groqdemo
cd 532-groqdemo
uv sync                          # creates .venv from pyproject.toml + uv.lock
cp .env.example .env             # paste your key into GROQ_API_KEY
uv run shiny run app.py          # http://127.0.0.1:8000/
```

Ask the sidebar *"Show only women who survived"* or *"What was the survival rate in third class?"*.
querychat turns the question into SQL, runs it in DuckDB on your machine, and updates the table.

The only provider-specific line in `app.py`:

```python
client=ChatGroq(model="qwen/qwen3.8-27b"),
```

## Run the evals

```bash
uv run pytest                                   # scoring logic, no API calls
uv run python evals/build_dataset.py            # regenerate targets after editing intents
evals/run_matrix.sh 3                           # 4 models × 7 cells × 3 epochs, ~1 h, parallel per model
uv run python evals/report.py                   # evals/results/summary.md (+ docs/eval-report.md)
uv run inspect view                             # browse per-sample logs
```

One cell of the matrix:

```bash
uv run inspect eval evals/qc_eval.py -T model=qwen/qwen3.8-27b -T config=format_query -T dataset=titanic \
  --epochs 3 --log-dir evals/logs --max-samples 3 --display plain
```

What is scored, and why, is in [`evals/README.md`](https://github.com/ilyamusabirov/532-groqdemo/blob/main/evals/README.md).
